# NBA canonical-game ID reconciliation

The read-only post-A/B source audit identified a consumer gap rather than 29 missing professional games. All 29 NBA game IDs have a unique explicit bridge to existing ESPN-ID canonical games in the retained licensed SportsDataverse 2027 schedule crosswalk (SHA-256 `db7ed5252ea5e72f4811da5daa70dff78ffc8ea570d8b50c60ccb1c0f7819a58`). No new Game or alias row was created.

The new binding requires the exact NBA and ESPN game IDs, source season/date, both NBA numeric participant IDs and both ESPN numeric participant IDs. The existing accepted V5 observation must independently agree with the date and both ESPN participants. Abbreviation differences such as WAS/WSH, NYK/NY, GSW/GS and SAS/SA therefore do not create a false hold. Date/team similarity alone is insufficient. Ambiguous publisher edges, conflicting accepted observations and changed reviewed proof fail closed.

`collectReadOnlyCompetitiveStages` decodes retained current release bodies and canonical bindings in a read-only repeatable transaction, returning stages, holds, source files, proof receipts and the exact source/canonical fingerprint. It performs no network request or canonical mutation. The CLI's `--extended-nba` writes a separate ignored queue; it preserves the frozen initial three-game and operational manifests.

Measured separate queue: **270 NBA games**, zero held games, **7,500** resolved statistical candidates and **254** complete-box binding candidates. Eighteen rows across six explicit player IDs remain held (`1631115`, `1641725`, `1642396`, `1642923`, `1642933`, `1643758`). Their retained source rows form a separate discovery proposal; neither name-only merging nor identity creation is authorized by this engineering fix. Individual DNP/participation gates remain independent of game identity binding.

The new optional reviewed game-identity proof is also checked at batch application: exact retained crosswalk bytes/unique row, accepted V5 observation fingerprint, canonical tuple and absence of a newer conflicting V5 head. Existing stages without an ID bridge retain their previous behavior. No schedule, time, original fantasy week, source dataset or historical result is rewritten.

The collector now supports the managed licensed NFL completed-results product `nfl-results-2026`: [nflverse-data schedules release](https://github.com/nflverse/nflverse-data/releases/tag/schedules), under its [CC BY 4.0 license](https://github.com/nflverse/nflverse-data/blob/main/LICENSE.md). Retrieval uses the existing bounded conditional GitHub transport; no raw-host expansion is necessary. Only season-2026 explicit, arithmetically consistent completed results become FINAL; incomplete records remain UNKNOWN. Original exact completion/publication instants remain null. This is operational result refresh, not V5 reacquisition or permission to promote historical/future canonical data automatically.

These changes prepare source queues only. The separate snapshot standing policy excludes statistics and boxes; recurring competitive processing requires its own bounded authorization and prospective cutover. No frozen batch was expanded.
