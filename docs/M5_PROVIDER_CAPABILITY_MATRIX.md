Reviewed November 26, 2026. Minimum viable permitted set: **nflverse plus SportsDataverse redistribution releases**. Keep the accepted historical/V5 inputs; add no paid dependency or separate per-league data service. Operational activation, request counters and health are reported by the central release scheduler; inclusion here does not authorize a development player/stat backfill.

Redistribution access does not authorize restricted direct league/ESPN APIs or image assets. GitHub distribution limits still apply; the local registry imposes conservative shared rolling budgets rather than claiming an unlimited publisher SLA.

## Closure classification

| Requirement gap | Class | Exact action |
| --- | --- | --- |
| Coarse NBA G/F families | Source has insufficient granularity + product decision | Choose an explicit fantasy mapping or retain granular-position pending state |
| Current listed positions/team/status without effective instant | Source lacks authoritative timestamps + evidence-policy decision | Approve a separately labeled snapshot/interval policy, or obtain exact effective timestamps |
| Minute-level official game times | Insufficient granularity; direct automated access permission separate | Apply only an approved precision policy to permitted evidence; never infer seconds or authorize a restricted collector |
| Official final-box original/correction publication | Field absent from chosen products | Preserve strict gate or explicitly approve a conservative alternative clock; obtain a source with the required semantics otherwise |
| NHL/MLB injury identity links | Identity mapping unresolved | Obtain explicit corroborated crosswalks; quarantine name-only candidates |
| Current NFL professional population outside accepted archive IDs | Review/implementation and concrete population approval | Review the prepared 1,248 direct-GSIS identities and 3,402 alias edges; six ambiguous same-name cases remain held; grant no fantasy eligibility |
| New NBA direct-ID cohort and validated aliases | Concrete backfill approval | Validate/apply the exact consolidated target; preserve all original rows and unknown eligibility |
| Direct restricted league/ESPN collectors | Licensing/permission unresolved | Written appropriate access/use permission; no task instruction substitutes for source rights |
| Commercial live feed | Payment/scope approval, optional | Not a prerequisite for free-release engineering or historical repair |

Reproduction: `node --import tsx src/workers/audit-provider-evidence.ts` performs bounded auxiliary retrieval, local decoding and read-only canonical joins. It never promotes development records. Accepted V5/recovered/Parquet inputs and user screenshots are untouched. Audited identity overlays and reviewed roster application use their own exact fingerprints; source research alone does not approve any canonical rewrite or merge.
